# Netflix Movies & TV Shows Analysis

## Project Overview

This project analyzes Netflix Movies and TV Shows using Python to explore the content available on the platform and identify key trends and insights.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

- Loaded and explored the Netflix dataset
- Checked and handled missing values
- Removed duplicate records
- Analyzed Movies and TV Shows
- Identified the countries with the most titles
- Identified the most common ratings
- Analyzed directors and actors
- Analyzed titles added by month and year
- Created bar, horizontal bar, pie, and line charts

## Key Findings

- Movies are more common than TV Shows
- The United States has the most Netflix titles
- 2019 had the highest number of titles added
- July had the highest number of titles added
- TV-MA was the most common rating
- Rajiv Chilaka had the most titles as a director
- Anupam Kher was the most frequently appearing actor
