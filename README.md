# Superstore Retail Sales — Exploratory Data Analysis

## Project Overview

This project explores the Superstore Retail Sales dataset using Python to identify sales patterns, understand customer purchasing behaviour, evaluate product performance and examine the relationship between discounts and profitability.

## Objectives

- Analyse monthly sales trends across different years.
- Examine customer purchasing behaviour and revenue contribution.
- Evaluate sales and profitability across product categories and sub-categories.
- Investigate the relationship between discounts and profit.
- Compare regional and customer segment performance.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

1. Data inspection and cleaning
2. Missing-value analysis
3. Date feature engineering
4. Monthly sales analysis
5. Customer purchasing behaviour
6. Category and sub-category performance
7. Discount sensitivity analysis
8. Regional performance
9. Customer segment analysis

## Key Findings

The analysis examines monthly sales variations, differences in customer revenue contribution, loss-making product sub-categories, discount-profit relationships and regional and customer segment profitability.

Detailed findings and recommendations are documented in the Jupyter Notebook.
