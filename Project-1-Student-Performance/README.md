# Student Performance Analysis

## Project Overview

This project analyzes students' performance using Python.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

## Analysis Performed

- Loaded data from a CSV file
- Calculated average scores
- Determined pass/fail status
- Filtered and sorted data
- Identified top-performing students
- Created bar and pie charts

## Skills Demonstrated

- Data cleaning
- Data analysis
- Data visualization
- Pandas
- NumPy
- Matplotlib
